# VitaPath

**Build Your Path. Present Your Best.**

VitaPath is a privacy-first document builder for students, scholarship applicants, and job seekers targeting Europe and GCC countries.

## Planned builders
- European CV
- Scholarship CV
- Motivation Letter
- Recommendation Letter
- GCC Resume + Cover Letter

## Security direction
VitaPath will use managed authentication rather than custom password storage, server-side authorization, encrypted transport, strict validation, secure sessions, rate limiting, least-privilege database access, and Cloudflare as an additional edge-security layer.

> Security is a process, not a promise of “100% secure.” Sensitive personal data must never be committed to this repository.
